# Code Formatting Rule

## Format Document on Edit
Always run a "Format document" lint/format check after editing any file.

## Formatting Guidelines
- Indentation: Use **Tabs** for indents (`UseTab: Always`).
- Tab width: **1 Tab = 4 spaces** (`TabWidth: 4`, `IndentWidth: 4`).
- Use `clang-format` with the configuration defined in [`.clang-format`](./.clang-format) to format C/C++ files.
