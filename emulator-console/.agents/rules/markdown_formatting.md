# Markdown and Text Formatting

- Do not use raw LaTeX math delimiters (`$...$`, `$$...$$`) for inequality signs, units, or simple formulas in chat responses.
- Use standard UTF-8 characters and Markdown formatting (e.g., `< 250 RPM`, `!= 0`, `degC`, `1/30`).
- Keep tables, code snippets, and lists clean and directly human-readable.
